# Quick Start Guide

## Get Started in 5 Minutes

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Set API Key
```bash
echo "PEXELS_API_KEY=your_key" > .env
```

### 3. Start Server
```bash
python backend/main.py
```

### 4. Generate Video
Open browser: `http://localhost:8000`

### 5. Enter Prompt
Example: "ocean waves at sunset"

That's it! Your video will be ready in ~30 seconds.
