# Navigation Structure

## Page Flow

```
landing.html (Home)
    ├── Get Started → get-started.html
    │   ├── Launch Dashboard → dashboard.html
    │   ├── View Documentation → GitHub
    │   └── Setup Guide → landing.html#how-it-works
    ├── Features → landing.html#features
    ├── How It Works → landing.html#how-it-works
    └── Examples → landing.html#examples
```

## Key Changes

The dashboard is now accessed through a dedicated "Get Started" page rather than directly from the landing page. This provides:

1. Better user flow and onboarding
2. Clear separation between marketing and application
3. Multiple entry points for different user needs
4. Improved navigation structure

## Links

- **Landing Page**: Main entry point with marketing content
- **Get Started Page**: Gateway to dashboard and resources
- **Dashboard**: Full application interface for video generation
