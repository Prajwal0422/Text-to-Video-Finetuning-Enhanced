## 🎨 Customization

### Change Colors
In `styles_enhanced.css`:
```css
--accent-primary: #6366f1;   /* Main color */
--accent-secondary: #8b5cf6; /* Secondary */
```

### Add Real Videos
Replace video placeholders with actual `<video>` tags:
```html
<video src="your-video.mp4" controls></video>
```

### Update Statistics
In `index_enhanced.html`, change `data-target` values:
```html
<div class="stat-number" data-target="3.2">0</div>
```
