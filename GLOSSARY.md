# Glossary

## Terms

### A
- **API**: Application Programming Interface
- **Analytics**: Usage tracking and statistics

### B
- **Batch Processing**: Processing multiple videos simultaneously
- **Bitrate**: Video data rate (affects quality and size)

### C
- **Clip**: Short video segment
- **Color Grading**: Adjusting colors for artistic effect
- **Codec**: Video compression algorithm

### D
- **Duration**: Video length in seconds

### E
- **Export**: Save video in specific format
- **Effect**: Visual modification applied to video

### F
- **FPS**: Frames Per Second
- **Frame**: Single image in video sequence

### G
- **Generation**: Creating video from text prompt
- **Grading**: See Color Grading

### I
- **Interpolation**: Creating intermediate frames

### L
- **LUT**: Look-Up Table for color grading

### P
- **Pipeline**: Series of processing steps
- **Preset**: Pre-configured settings

### R
- **Resolution**: Video dimensions (width x height)
- **Rendering**: Final video creation process

### S
- **Stabilization**: Removing camera shake
- **Subtitle**: Text overlay on video

### T
- **Template**: Pre-configured video format
- **Transition**: Effect between clips

### W
- **Watermark**: Logo or text overlay
- **Workflow**: Series of operations

## Acronyms
- API: Application Programming Interface
- FPS: Frames Per Second
- HD: High Definition
- LUT: Look-Up Table
- MP4: MPEG-4 video format
- SRT: SubRip subtitle format
